Self-hosted variable fonts (Latin subset), copied from the @fontsource-variable packages, version 5.3.0, on 2026-11-01. All four families are published under the SIL Open Font License 1.1. They replaced next/font/google because Google's CSS endpoint intermittently returned something the loader could not parse during concurrent builds, which failed the Vercel and GitHub Actions builds (next/font "Cannot read properties of null (reading '1')").
